2.3.1 Target Bed

Note a targeted panel was used for this analysis, which is loaded into the variable TargetBed

TargetBed <- read.delim(AllDat$Annot$Bed, header = F, sep = "\t")
TargetBedGR <- GRanges(seqnames = TargetBed$V1, ranges = IRanges(start = TargetBed$V2, end = TargetBed$V3), Gene = TargetBed$V4)
TargetBedGR$width <- width(TargetBedGR)
genesB <- unique(TargetBed$V4)
genesB2 <- genesB[-grep("_[0-9]+", genesB)]

There are 636 targets and 6929 intervals in this panel featuring 464.

Below is a summary table of chromosomal locations and genes in close proximity (using a sliding window of 10MB):

Windows <- GenomeLocationSeg(AllDat$Annot$Bed, AllDat$Annot$HgChr, windsize = 1E7)

2.3.2 Cancer Gene Census

The cancer gene census was downloaded from cosmic. This can be loaded to filter out oesophagael specific genes. There are two tables loaded: CmcOesoph which is an Oseophageal specific Cosmic List, and CmcHallmark which is List of Cosmic Hallmark genes

CosmicList <- read.csv(AllDat$Annot$CancerCensus)
CmcOesoph <- CosmicList[grep("oesoph", CosmicList$Tumour.Types.Somatic.), ]
CmcHallmark <- CosmicList[unique(c(
     grep("oesoph", CosmicList$Tumour.Types.Somatic.),
     which(CosmicList$Hallmark == "Yes")
)), ]

Pan-TCGA pathways, extracted from pathway mapper, and used to visualise abberant pathways in cbioportal is saved in the variable TCGApathways

TCGApathways <- read.csv(AllDat$Annot$TCGApathway, stringsAsFactors = F)
tmpnam <- colnames(TCGApathways)
TCGApathways <- lapply(1:ncol(TCGApathways), function(x) setdiff(unique(TCGApathways[, x]), ""))
names(TCGApathways) <- tmpnam
